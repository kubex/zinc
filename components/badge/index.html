Badge

<zn-badge> ZnBadge
Since 1.0 experimental

Badges label the status or category of a record, such as “Active” or “Past due”.

Neutral Active Past due Cancelled Trial AI suggested Completed Failed VIP Urgent Large 
<zn-badge>Neutral</zn-badge>
<zn-badge type="success">Active</zn-badge>
<zn-badge type="warning">Past due</zn-badge>
<zn-badge type="danger">Cancelled</zn-badge>
<zn-badge type="info">Trial</zn-badge>
<zn-badge type="ai">AI suggested</zn-badge>
<zn-badge type="success" dot>Completed</zn-badge>
<zn-badge type="danger" dot>Failed</zn-badge>
<zn-badge type="info" solid>VIP</zn-badge>
<zn-badge type="danger" solid>Urgent</zn-badge>
<zn-badge type="success" size="large" dot>Large</zn-badge>

Examples

Types

Use the type attribute to set the badge’s colour: neutral (default), success, warning, danger, info or ai. Reserve ai for AI-generated content — it is the only type that carries an icon.

Neutral Active Past due Cancelled Trial AI suggested 
<zn-badge>Neutral</zn-badge>
<zn-badge type="success">Active</zn-badge>
<zn-badge type="warning">Past due</zn-badge>
<zn-badge type="danger">Cancelled</zn-badge>
<zn-badge type="info">Trial</zn-badge>
<zn-badge type="ai">AI suggested</zn-badge>

Status Dot

Use dot to lead the label with a status indicator in the type colour.

Completed Pending Failed Draft 
<zn-badge type="success" dot>Completed</zn-badge>
<zn-badge type="warning" dot>Pending</zn-badge>
<zn-badge type="danger" dot>Failed</zn-badge>
<zn-badge dot>Draft</zn-badge>

Solid

Use solid to fill the badge with its type colour for labels that need to stand out, such as VIP or urgent.

VIP Urgent Paid Overdue 
<zn-badge type="info" solid>VIP</zn-badge>
<zn-badge type="danger" solid>Urgent</zn-badge>
<zn-badge type="success" solid>Paid</zn-badge>
<zn-badge type="warning" solid>Overdue</zn-badge>

Large

Use size="large" for a larger badge.

Large AI suggested Urgent 
<zn-badge type="success" size="large" dot>Large</zn-badge>
<zn-badge type="ai" size="large">AI suggested</zn-badge>
<zn-badge type="danger" size="large" solid>Urgent</zn-badge>

Clickable

Add <zn-option> elements to make the badge open a dropdown of choices, like a select. The badge shows the selected option’s label and takes each option’s own type and dot. Listen for zn-change and read value. The tooltip shows below the badge; set tooltip-placement to move it.

Inside a form, give the badge a name to submit the selected value, and add trigger-submit to submit the form as soon as an option is picked.

New Open Pending On hold Solved Low Normal High Urgent 
<zn-badge class="badge-status" value="open" tooltip="Change status">
  <zn-option value="new" type="info" dot>New</zn-option>
  <zn-option value="open" type="success" dot>Open</zn-option>
  <zn-option value="pending" dot>Pending</zn-option>
  <zn-option value="on-hold" type="warning" dot>On hold</zn-option>
  <zn-option value="solved" dot>Solved</zn-option>
</zn-badge>
<zn-badge value="normal" tooltip="Change priority">
  <zn-option value="low">Low</zn-option>
  <zn-option value="normal" type="info">Normal</zn-option>
  <zn-option value="high" type="warning">High</zn-option>
  <zn-option value="urgent" type="danger">Urgent</zn-option>
</zn-badge>

<script type="module">
  document.querySelector('.badge-status').addEventListener('zn-change', e => console.log(e.target.value));
</script>

Importing

If you’re using the autoloader or the traditional loader, you can ignore this section. Otherwise, feel free to use any of the following snippets to cherry pick this component.

To import this component from the CDN using a script tag: 

<script type="module" src="https://cdn.jsdelivr.net/npm/@kubex/zinc@2.0.14/dist/components/badge/badge.js"></script>

To import this component from the CDN using a JavaScript import: 

import 'https://cdn.jsdelivr.net/npm/@kubex/zinc@2.0.14/dist/components/badge/badge.js';

To import this component using a bundler:

import '@kubex/zinc/dist/components/badge/badge.js';

Slots

Name Description
(default) The badge’s label, or <zn-option> elements to make the badge a clickable select. An option’s own type and dot attributes style the badge while it is selected. With a name, the selected value is submitted with its form.

Learn more about using slots.

Properties

Name Description Reflects Type Default
type ai marks AI-generated content only. 'neutral' | 'success' | 'warning' | 'danger' | 'info' | 'ai' 'neutral'
solid Fills the badge with its type colour. boolean false
dot Leads the label with a dot in the type colour. boolean false
value The selected option’s value, when the badge holds <zn-option> elements. string ''
name Submits the selected value under this name. string ''
triggerSubmit
trigger-submit 		Submits the badge’s form as soon as an option is picked. boolean false
tooltip Tooltip shown on hover, such as “Change status”. string -
updateComplete A read-only promise that resolves when the component has finished updating.

Learn more about attributes and properties.
