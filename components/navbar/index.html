Pill

Add the pill attribute to draw the tabs as a segmented control: a grey track with a raised pill that slides to the active tab, stretching and settling with a spring as it moves.

All
Active
Draft
Archived
 
<zn-tabs>
  <zn-navbar slot="top" pill navigation='[{"tab":"","title":"All"},{"tab":"active","title":"Active"},{"tab":"draft","title":"Draft"},{"tab":"archived","title":"Archived"}]'></zn-navbar>
  <div id="">All</div>
  <div id="active">Active</div>
  <div id="draft">Draft</div>
  <div id="archived">Archived</div>
</zn-tabs>

Sliding Indicator

Set --zn-navbar-tab-indicator-slide: 1 to replace each tab’s own line with a single indicator that slides to the active tab. Style it with ::part(indicator); --zn-navbar-indicator-top and --zn-navbar-indicator-height give the active tab’s box, so the indicator can fill the tab as a pill instead of underlining it.

Active
Draft
Archived
 
<style>
  .pill-tabs zn-navbar {
    --zn-navbar-tab-indicator-slide: 1;
    --zn-navbar-tab-background: transparent;
    --zn-navbar-tab-hover-background: transparent;
    --zn-navbar-tab-hover-backdrop: transparent;
    --zn-navbar-tab-active-background: transparent;
  }

  .pill-tabs zn-navbar::part(container) {
    border-bottom: 0;
  }

  .pill-tabs zn-navbar::part(navbar) {
    width: fit-content;
    height: auto;
    padding: 4px;
    border-radius: 10px;
    background: var(--zn-color-neutral-100);
  }

  .pill-tabs zn-navbar::part(navbar-item) {
    z-index: 1;
    min-height: 32px;
    border: 0;
  }

  .pill-tabs zn-navbar::part(indicator) {
    z-index: 0;
    top: var(--zn-navbar-indicator-top);
    bottom: auto;
    height: var(--zn-navbar-indicator-height);
    border-radius: 7px;
    background: #fff;
    box-shadow: 0 1px 2px rgba(0, 0, 0, 0.08), 0 1px 3px rgba(0, 0, 0, 0.06);
  }
</style>

Liquid Indicator

zn-navbar pill draws the tabs as a segmented control with this motion built in. The indicator moves by its two edges: on a tab change it squishes slightly during --zn-navbar-tab-indicator-delay, then its leading edge glides to the new tab while the trailing edge follows on a damped spring, so it stretches a little and settles. Neither edge travels beyond the new tab. Reduced motion turns all of this off.

All
Active
Draft
Suspended
Archived
 
<style>
  .liquid-tabs zn-navbar {
    /* Squish, then move once the squish is at its deepest */
    --zn-navbar-tab-indicator-delay: 60ms;
    --zn-navbar-tab-indicator-squash: 0.87;
    /* The leading edge glides in on a drawer curve */
    --zn-navbar-tab-indicator-duration: 280ms;
    --zn-navbar-tab-indicator-easing: cubic-bezier(0.32, 0.72, 0, 1);
    /* The trailing edge follows on a spring that overshoots once as it catches up */
    --zn-navbar-tab-indicator-trail-duration: 400ms;
    --zn-navbar-tab-indicator-trail-easing: linear(0, 0.044, 0.151, 0.286, 0.428, 0.562, 0.681, 0.78, 0.86, 0.92, 0.964, 0.993, 1.012, 1.023, 1.028, 1.028, 1.026, 1.023, 1.019, 1.015, 1.011, 1.008, 1.005, 1.003, 1.002, 1.001, 1, 1, 1);
  }
</style>

<zn-tabs class="pill-tabs liquid-tabs">
  <zn-navbar slot="top" navigation='[{"tab":"","title":"All"},{"tab":"active","title":"Active"},{"tab":"draft","title":"Draft"},{"tab":"suspended","title":"Suspended"},{"tab":"archived","title":"Archived"}]'></zn-navbar>

  <div id="active">Active</div>
  <div id="draft">Draft</div>

</zn-tabs>

Importing

If you’re using the autoloader or the traditional loader, you can ignore this section. Otherwise, feel free to use any of the following snippets to cherry pick this component.

To import this component from the CDN using a script tag: 

<script type="module" src="https://cdn.jsdelivr.net/npm/@kubex/zinc@2.0.2/dist/components/navbar/navbar.js"></script>

To import this component from the CDN using a JavaScript import: 

import 'https://cdn.jsdelivr.net/npm/@kubex/zinc@2.0.2/dist/components/navbar/navbar.js';

To import this component using a bundler:

import '@kubex/zinc/dist/components/navbar/navbar.js';

Properties

Name Description Reflects Type Default
pill Draws the tabs as a segmented control: a grey track with a pill that slides to the active tab. boolean false
size With pill, small draws a shorter track to sit with small controls, such as above a form field. 'small' | 'medium' 'medium'
tabs The id of a zn-tabs elsewhere on the page that this navbar’s tabs switch, such as one below a page header. string -
updateComplete A read-only promise that resolves when the component has finished updating.

Custom Properties

Name Description Default
--zn-navbar-tab-indicator-slide 1 shows the sliding indicator in place of each tab’s own line.
--zn-navbar-tab-indicator-duration Duration of the indicator’s leading edge (default 300ms).
--zn-navbar-tab-indicator-easing Easing of both indicator edges.
--zn-navbar-tab-indicator-trail-duration Duration of the trailing edge; longer than the lead stretches the indicator.
--zn-navbar-tab-indicator-trail-easing Easing of the trailing edge; defaults to --zn-navbar-tab-indicator-easing.
--zn-navbar-tab-indicator-trail-delay Delay before the trailing edge follows (default 0ms).
--zn-navbar-tab-indicator-delay Delay before the indicator starts to move (default 0ms).
--zn-navbar-tab-indicator-squash Vertical scale the indicator squishes to before it travels (default 1, off).

Learn more about customizing CSS custom properties.

Parts

Name Description
base The component’s base wrapper.
indicator The active-tab indicator that slides between tabs. Exposes --zn-navbar-indicator-top / --zn-navbar-indicator-height (the active tab’s box) for styles that fill the tab.
