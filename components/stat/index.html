Stats Tile

<zn-stat> | ZnStatsTile
Since 1.0 experimental

Displays a key metric, optionally compared with a previous value.

<zn-cols>
  <zn-panel>
    <zn-stat caption="Total Revenue" description="This month" amount="48250" previous="42100" currency="$" show-delta></zn-stat>
  </zn-panel>
</zn-cols>

Examples

Basic Stat

A basic stat displays a caption, description, and amount.

<zn-cols>
  <zn-panel>
    <zn-stat caption="Total Users" description="Active accounts" amount="1247"></zn-stat>
  </zn-panel>
</zn-cols>

Currency Formatting

Use the currency attribute to automatically format monetary values with proper comma separators and decimal places. 

<zn-cols>
  <zn-panel>
    <zn-stat caption="Monthly Revenue" description="January 2026" amount="125750.50" currency="$" color="success"></zn-stat>
  </zn-panel>
  <zn-panel>
    <zn-stat caption="Total Sales" description="This quarter" amount="487999.99" currency="$" color="info"></zn-stat>
  </zn-panel>
  <zn-panel>
    <zn-stat caption="Outstanding Balance" description="Accounts receivable" amount="23450" currency="$" color="warning"></zn-stat>
  </zn-panel>
</zn-cols>

<zn-cols>

Delta Comparison

Use the show-delta attribute with previous to show the percentage change from a previous period. 

<zn-cols>
  <zn-panel>
    <zn-stat caption="New Users" description="This week" amount="324" previous="280" show-delta color="success"></zn-stat>
  </zn-panel>
  <zn-panel>
    <zn-stat caption="Revenue" description="This month" amount="45600" previous="52300" currency="$" show-delta color="error"></zn-stat>
  </zn-panel>
  <zn-panel>
    <zn-stat caption="Conversion Rate" description="Last 30 days" amount="3.2" previous="3.2" type="percent" show-delta color="neutral"></zn-stat>
  </zn-panel>
</zn-cols>

Value First

Use layout="value-first" to show the amount under the caption, with the description beneath it in muted text. In this layout color tints the amount, so use color="neutral" for plain figures and a semantic color to flag one. Each stat has a box of its own, so zn-cols divide draws lines between them. The example adds size="large" for headline figures. 

<zn-panel caption="Last 30 days">
  <zn-cols layout="1,1,1,1" divide>
    <zn-stat layout="value-first" size="large" caption="Quality score" description="Weighted by points" amount="88.9" previous="86.5" type="percent" delta-format="points" show-delta color="neutral"></zn-stat>
    <zn-stat layout="value-first" size="large" caption="Evaluations" description="Completed assessments" amount="42" color="neutral"></zn-stat>
    <zn-stat layout="value-first" size="large" caption="Fails" description="1 automatic" amount="3" color="error"></zn-stat>
    <zn-stat layout="value-first" size="large" caption="Kudos" description="From reviewers" amount="2" icon="award@lu" color="neutral"></zn-stat>
  </zn-cols>
</zn-panel>

Padded

Use padded to give each stat its own padding, for stats laid edge to edge in a flush panel. With zn-cols no-gap divide the dividers run the full height of the panel body. 

<zn-panel caption="Last 30 days" flush>
  <zn-cols layout="1,1,1" no-gap divide stack-at="md">
    <zn-stat layout="value-first" size="large" padded caption="Quality score" description="Weighted by points" amount="88.9" type="percent" color="neutral"></zn-stat>
    <zn-stat layout="value-first" size="large" padded caption="Evaluations" description="Completed assessments" amount="42" color="neutral"></zn-stat>
    <zn-stat layout="value-first" size="large" padded caption="Fails" description="1 automatic" amount="3" color="error"></zn-stat>
  </zn-cols>
</zn-panel>

Large

Use size="large" to give the amount more weight, for a row of a few headline figures.

<zn-cols>
  <zn-panel>
    <zn-stat size="large" caption="Total Users" description="Active accounts" amount="1247"></zn-stat>
  </zn-panel>
  <zn-panel>
    <zn-stat size="large" caption="Conversion Rate" description="Last 30 days" amount="4.8" type="percent" color="success"></zn-stat>
  </zn-panel>
</zn-cols>

Delta In Points

Use delta-format="points" with show-delta to show the difference between amount and previous in points rather than the relative change. This suits values that are already percentages. 

<zn-cols>
  <zn-panel>
    <zn-stat caption="Pass rate" description="This month" amount="91.5" previous="88.2" type="percent" delta-format="points" show-delta color="success"></zn-stat>
  </zn-panel>
  <zn-panel>
    <zn-stat caption="Error rate" description="Last 24 hours" amount="2.1" previous="3.4" type="percent" delta-format="points" show-delta color="neutral"></zn-stat>
  </zn-panel>
</zn-cols>

Tile

Use layout="tile" for a self-contained stat card: the caption, the amount, a footer with the delta and description, and an optional sparkline from comma-separated spark values. Colour the sparkline with spark-color (a tone such as success or danger, or any CSS colour). Set invert-delta where a rise is bad news. 

<zn-cols layout="1,1,1">
  <zn-stat layout="tile" caption="Pending commission" amount="$2,941" show-delta previous="$2,875"
           description="vs. 1,875" spark="4,6,5,8,7,10,9,13,12,15"></zn-stat>
  <zn-stat layout="tile" caption="Unpaid paychecks" amount="$841" show-delta previous="$851"
           description="vs. 902" spark="12,11,13,10,9,10,8,9,7,6" spark-color="danger"></zn-stat>
  <zn-stat layout="tile" caption="Declined" amount="148" show-delta previous="140" invert-delta
           description="3.4% of orders" spark="6,5,7,4,6,5,5,4,6,5,4,5,4,5,4" spark-color="danger"></zn-stat>
</zn-cols>

Selectable Tiles

Add selectable to make a tile a toggle button, for tiles that filter the content below them, and tone for a coloured dot before the caption. selected sets the pressed state. 

<zn-cols layout="1,1,1">
  <zn-stat layout="tile" selectable tone="info" caption="Capturing payment" amount="28"
           description="Oldest 11 h" spark="0,0,1,0,2,1,0,3,2,4,3,5,8,12,28" spark-color="info"></zn-stat>
  <zn-stat layout="tile" selectable selected tone="warning" caption="Awaiting approval" amount="203"
           description="Oldest 29 days" spark="9,7,8,11,9,6,8,10,7,9,12,8,9,10,11" spark-color="warning"></zn-stat>
  <zn-stat layout="tile" selectable tone="success" caption="Complete" amount="3,481" show-delta previous="3,513"
           description="80% of orders" spark="120,128,119,124,118,131,127,122,126,130" spark-color="success"></zn-stat>
</zn-cols>

Importing

If you’re using the autoloader or the traditional loader, you can ignore this section. Otherwise, feel free to use any of the following snippets to cherry pick this component.

To import this component from the CDN using a script tag: 

<script type="module" src="https://cdn.jsdelivr.net/npm/@kubex/zinc@2.0.10/dist/components/stat/stat.js"></script>

To import this component from the CDN using a JavaScript import: 

import 'https://cdn.jsdelivr.net/npm/@kubex/zinc@2.0.10/dist/components/stat/stat.js';

To import this component using a bundler:

import '@kubex/zinc/dist/components/stat/stat.js';

Properties

Name Description Reflects Type Default
layout value-first puts the amount under the caption with the description beneath it, and tints the amount rather than the description with color. tile is a self-contained card: caption, amount, a footer with the delta and description, an optional sparkline, and the default slot beneath. 'default' | 'value-first' | 'tile' 'default'
spark Comma-separated values drawn as a sparkline under a tile. string ''
sparkColor
spark-color 		The sparkline’s colour: a tone (primary, info, success, warning, danger, ai) or any CSS colour. string ''
invertDelta
invert-delta 		Treats a rise as bad news, so an increase is coloured as a loss (declines, refunds, failures). boolean false
tone A coloured dot before a tile’s caption. '' | 'info' | 'success' | 'warning' | 'danger' | 'neutral' ''
selectable Renders a tile as a toggle button, for tiles that filter the content below them. boolean false
